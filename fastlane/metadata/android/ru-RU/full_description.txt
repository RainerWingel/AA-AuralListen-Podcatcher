<p>AA-AuralListen Podcatcher — приватное приложение для подкастов на Android. Только аудио, без аккаунта, без рекламы, без слежки. Всё остаётся на вашем телефоне — у разработчика нет никакого сервера.</p>

<p><b>Поиск и подписка</b></p>
<ul>
<li>Поиск в Apple Podcasts и fyyd.de, подписка по RSS-адресу, импорт и экспорт OPML</li>
<li>Новые подкасты сначала временные: послушайте (онлайн), потом подпишитесь</li>
<li>Оценки от 1 до 5 звёзд — подписки сортируются по ним</li>
<li>Потяните вниз для обновления, со строкой статуса; переехавшие подкасты (новый адрес ленты) отслеживаются автоматически</li>
<li>Красный счётчик непрослушанных выпусков; поиск по подпискам</li>
<li>Страница подкаста со сворачиваемым описанием, сайтом и ссылкой для поддержки</li>
<li>Поиск с «Популярное» (чарты Apple) и «Новинки» — по языку приложения</li>
<li>Главная: огонёк у подкастов, которые вы почти никогда не пропускаете</li>
<li>Сезоны: «S2·5» на обложке и фильтр; сериалы в порядке прослушивания</li>
</ul>

<p><b>Прослушивание</b></p>
<ul>
<li>Фоновое воспроизведение, экран блокировки, управление по Bluetooth</li>
<li>Перемотка −15 с / +30 с (удерживайте для быстрой перемотки); скорость от 1,0× до 2,0× и усиление громкости — для всех или для отдельного подкаста</li>
<li>Оставшееся время или общая длительность; на высокой скорости — также реальное оставшееся время</li>
<li>Описание выпуска с кликабельными ссылками</li>
<li>Главы (Podlove, JSON, ID3) с картинками и пропуском глав; закладки с заметками</li>
<li>Таймер сна с плавным затуханием, также «до конца выпуска»</li>
<li>Позиция каждого выпуска сохраняется; прослушанным выпуск считается только в конце</li>
<li>История последних 100 выпусков, прослушанных до конца</li>
<li>Устойчивость к обрывам сети и MP3 с переменным битрейтом</li>
</ul>

<p><b>Плеер</b></p>
<ul>
<li>Полоса прокрутки и кнопки закреплены внизу, остальное прокручивается</li>
<li>Размытая обложка на фоне</li>
<li>Отдельная альбомная раскладка: информация слева, управление справа</li>
<li>Фон панели плеера на выбор (Настройки → Дизайн): звёздное небо, северное сияние, волны, кристалл, камуфляж</li>
</ul>

<p><b>Плейлисты</b></p>
<ul>
<li>Несколько плейлистов, которые играют дальше сами, с цветами, сортировкой и «Продолжить»</li>
<li>«Воспроизвести следующим» и «Добавить в конец» для играющего плейлиста; ⏮ ⏭ в плеере и по Bluetooth</li>
<li>Прослушанные выпуски уходят из плейлиста сразу, через 5 минут или никогда — на ваш выбор</li>
<li>Новые выпуски — в плейлист, даже без скачивания</li>
<li>Новые или непрослушанные выпуски подкаста, темы или сезона — в плейлист</li>
<li>Значок у каждого выпуска, который есть в плейлисте</li>
</ul>

<p><b>Android Auto</b></p>
<ul>
<li>Плейлисты, новые выпуски, загрузки и подписки в машине; −15 с / +30 с и ⏭; голосовые команды («Окей, Google, включи плейлист … в AA-AuralListen»)</li>
<li>Не из Play Store: один раз включите «Неизвестные источники» в настройках для разработчиков Android Auto</li>
</ul>

<p><b>Загрузки</b></p>
<ul>
<li>Ручная или автоматическая загрузка для каждого подкаста, по желанию сразу в плейлист; режим «По Wi-Fi»</li>
<li>Ленты радиостанций: загрузка только выбранных тем</li>
<li>Прослушанные загрузки удаляются через 96 часов; настраиваемый лимит памяти</li>
</ul>

<p><b>И ещё</b></p>
<ul>
<li>Русский, немецкий, английский, французский, испанский, португальский и итальянский; светлая и тёмная тема, цвет на выбор или по обоям (Android 12+)</li>
<li>Номера выпусков на обложках, резервное копирование и восстановление</li>
</ul>

<p>Поиск подкастов использует iTunes Search API от Apple и fyyd.de; им передаётся ваш поисковый запрос. Всё остальное соединяется напрямую с авторами подкастов.</p>
